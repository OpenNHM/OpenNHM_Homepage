As part of the OpenNHM initiative announced earlier this year, we are excited to share two important milestones in our
transition.
 
**New Homepage**

Our main website has moved from **avaframe.org** to **[opennhm.org](https://opennhm.org)**.

**GitHub Repository Migration**

The **AvaFrame repository** is moving from the `avaframe` organization to the **[OpenNHM GitHub organization](https://github.com/opennhm)**.

**What This Means for Users**

- **Repository URL**: The repository will be accessible at `github.com/opennhm/AvaFrame`
- **Redirects**: GitHub automatically redirects from the old URL, so existing clones and forks will continue to work
- **Documentation**: All documentation links will be updated to reflect the new organization
- **Functionality**: No changes to the code or functionality of AvaFrame

**Looking Ahead**

These changes represent significant steps in realizing the OpenNHM vision of creating an accessible, collaborative
ecosystem for natural hazard modeling.

We continue to invite researchers, practitioners, and institutions worldwide to join this effort.

For questions or to express interest in contributing, please contact us through our usual channels.
