Welcome to the December 2025 update, where no PRs were merged into master branch, but there is ongoing work…

**Generic Topography Representative**

We are creating a generic topography representative for debris flows. This will provide standardized test cases for
model validation and benchmarking specific to debris flow characteristics.

**Time-Dependent Release Options**

We are working on improvements for time-dependent release options, which will allow hydrographs as input data, for
example. This builds on the initial hydrograph functionality introduced in PR #1167 and addresses issues raised in
DebrisFrame Issue #13.

We will announce further developments in January.
