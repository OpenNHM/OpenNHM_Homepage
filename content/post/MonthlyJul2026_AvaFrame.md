Welcome to the July 2026 edition of the AvaFrame monthly update:

This month brought new asset analysis functionality, improvements to running
FlowPy from other projects, and clearer simulation reports. We also fixed
a Windows issue affecting the OpenNHM QGIS Connector and expanded benchmark
coverage for time-dependent release with entrainment.

## Features

**Asset Analysis and Plotting**

- **PR #1277** ([link](https://github.com/OpenNHM/AvaFrame/pull/1277))
  added tools for analysing simulation particles in relation to assets,
  including a dedicated runscript and plotting functionality.
- **PR #1303** ([link](https://github.com/OpenNHM/AvaFrame/pull/1303))
  added a debug plot for the dense flow module.

**FlowPy Integration**

- **PR #1298** ([link](https://github.com/OpenNHM/AvaFrame/pull/1298))
  enabled running FlowPy from another repository with configuration
  overrides. It also added simulation status information and control
  over rerunning simulations when results already exist.

**Configuration and Reports**

- **PR #1305** ([link](https://github.com/OpenNHM/AvaFrame/pull/1305))
  updated the com8 configuration for the new `.rcf` file version and
  MoT-PSA code changes.
- **PR #1315** ([link](https://github.com/OpenNHM/AvaFrame/pull/1315))
  clarified that projected and actual release areas in com1DFA reports
  are calculated from the release raster. These approximate the polygon
  area, with differences depending on mesh cell size.

## Bug Fixes

- **PR #1308** ([link](https://github.com/OpenNHM/AvaFrame/pull/1308))
  fixed handling of `nan` values during numeric conversion, resolving
  an issue encountered when using the OpenNHM QGIS Connector on Windows.
- **PR #1318** ([link](https://github.com/OpenNHM/AvaFrame/pull/1318))
  restricted entrainable deposition checks to com1DFA, com5SnowSlide,
  and com6RockAvalanche rather than applying them to other modules.

## Documentation

- **PR #1313** ([link](https://github.com/OpenNHM/AvaFrame/pull/1313))
  corrected information about resistance in the dense flow module
  documentation.

## Testing and Infrastructure

- **PR #1301** ([link](https://github.com/OpenNHM/AvaFrame/pull/1301))
  added benchmark data for time-dependent release with entrainment.
- **PR #1314** ([link](https://github.com/OpenNHM/AvaFrame/pull/1314))
  moved files generated by probability analysis tests to temporary paths,
  keeping test output out of project directories.
- **PR #1317** ([link](https://github.com/OpenNHM/AvaFrame/pull/1317))
  updated assertions in the general configuration tests.
- **PR #1309** ([link](https://github.com/OpenNHM/AvaFrame/pull/1309))
  introduced a pull request checklist template and an automated check
  requiring checklist completion.


See you in August!
